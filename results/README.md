# Experiment results

These CSV files are produced by `python -m src.run_analysis`.

- `closure_comparison_results.csv` contains the main random and highest-use comparison.
- `random_run_results.csv` contains every repeated random run.
- `tie_sensitivity_results.csv` compares all fourth-road tie choices.
- `network_seed_results.csv` compares ten road-distance seeds.
- `travel_cost_results.csv` contains the optional static edge-cost check.

The generated files are kept in the repository so the reported values can be checked without rerunning the code.
